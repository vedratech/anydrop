First release of the React package. It has an `<AnyDrop>` component with an `on<Event>` prop for every event, render props (`renderFile`, `renderFolder`, `renderToolbar`, `renderMessage`, `renderErrorItem`) that mount real React components in your tree, a ref to the instance, and a headless `useAnyDrop` hook with state. It works with React 18 and 19, StrictMode and the Next.js App Router.
