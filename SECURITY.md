# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 1.x | Yes |
| older than 1.0 | No (please upgrade) |

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through GitHub instead:
1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, the affected package and version, and how to reproduce it.

We aim to reply within 5 working days, and to publish a fix and an advisory as soon as it is confirmed.

AnyDrop runs in the browser and talks to your own backend. Problems in your server code are out of scope, but reports about the documented protocol or the backend examples in the docs (for example path handling) are welcome.
