The markup and options below are the ones from the Dropzone documentation (Dropzone.options.myAwesomeDropzone, a form with an action, a custom accept).

Folder tree

Chunked upload with a manifest, a collapsible tree, per-folder progress and controls. Drop a folder, or use Select folder.

Headless (no UI package)

The core engine alone, with a hand-made input and log.


    


    

      
Mobile layout

      

        A 360 px wide column. On touch devices the zone becomes one full-width tap-to-upload button.
      

      

        

      

    


    

      
Errors and retry

      

        Only .txt and .bin files up to 1 MB are accepted. Use the buttons
        to make the server fail, then press Retry failed.
      

      

        
        
      

      

    

    

      
Offline and network

      

        Start an upload, then press Simulate outage: uploads go to a dead address, so
        requests end without any response (like a Wi-Fi without internet). The banner shows the
        countdown and Retry now. Restore points uploads back at the mock. To test
        the offline state, open DevTools, Network, and choose Offline (or use
        context.setOffline(true) in Playwright). Needs core with the connection API
        (decision 0017); until then the banner stays hidden.
